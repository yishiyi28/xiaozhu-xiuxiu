# AI 放大

小猪修修提供可选的 AI 放大工作流。应用本身不包含 Upscayl、NCNN 可执行文件或第三方模型；用户需要使用单独安装的 Upscayl 兼容后端。

## 准备后端

AI 放大需要两部分：

1. Upscayl 兼容的 `upscayl-bin` 可执行文件。
2. 至少一组配套模型文件：同名的 `.param` 和 `.bin`。

在小猪修修中选择 **图像 → AI 放大…**，设置：

- **后端程序**：例如 Windows 下的 `upscayl-bin.exe`。
- **模型文件夹**：包含 `.param` 和 `.bin` 文件的目录。
- **模型**：从小猪修修扫描到的模型列表中选择。
- **倍率**：2×、3× 或 4×。
- **分块大小**：0 表示使用后端默认值。显存不足时可以从 256 或 128 开始尝试。
- **TTA 模式**：质量更高但速度明显更慢。
- **GPU 编号**：可选，对应后端的 GPU 索引。

配置会保存在小猪修修的用户配置文件中。

也可以从 **编辑 → AI 放大…** 在没有打开图片时提前配置。选择 Upscayl 安装目录中 `resources/bin/upscayl-bin` 时，小猪修修会尝试自动填入相邻的 `resources/models` 目录。

## 单张图片

打开图片或项目后，从 **图像 → AI 放大…** 启动。处理时会把当前合成结果扁平化为 8-bit PNG 输入后端，完成后作为新的 `.xuan` 文档打开。

AI 放大不会保留：

- 原始图层结构；
- 16-bit 像素精度；
- 项目内蒙版和智能对象；
- 原始 RAW Develop 状态。

需要保留这些内容时，请先保存原项目，再对导出副本执行 AI 放大。

## 批量输出

在批量出片窗口中勾选 **AI 放大输出**。批量任务会：

1. 读取输入图片；
2. 应用全局预设和逐文件覆盖；
3. 应用最长边设置；
4. 将当前结果扁平化并送入 AI 后端；
5. 将放大结果转换为目标格式并写入输出目录。

逐文件预设覆盖、失败重试和前后结果对比继续有效。AI 放大每一张图片都会单独启动一次后端，因此大量图片的处理时间会明显高于普通批量导出。

## 故障排查

- **找不到模型**：确认文件夹中存在同名的 `.param` 和 `.bin`，然后点击“刷新模型”。
- **后端起不来**：确认文件路径可执行，并尝试在终端直接运行后端。
- **显存不足**：降低分块大小，或关闭 TTA。
- **输出是扁平的**：这是当前外部后端工作流的预期行为。
- **速度很慢**：AI 放大依赖 Vulkan GPU；TTA、4× 和大尺寸输入都会显著增加耗时。
