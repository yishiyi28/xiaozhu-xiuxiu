# 小猪修修 0.6.0 人像精修与一键出片 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 发布 0.6.0，提供本地多人脸分析、可撤销人像精修、手动液化、`.xzp` 预设和批量出片。

**Architecture:** 新增独立 `portrait` 核心库，使用嵌入的 Apache-2.0 ONNX 模型和纯 Rust `tract` 推理；桌面层负责异步分析、降采样预览和单事务提交。调色通过新的 `ColorGrade` 调整层保持非破坏性，人像与液化在全分辨率应用时生成新像素并作为一个历史步骤提交。批量引擎复用同一套分析、预设和导出代码，逐张原子写入。

**Tech Stack:** Rust 1.91、tract 0.23.9、ONNX、egui/eframe、wgpu、image、serde/serde_json、clap、tempfile。

**Spec:** `docs/superpowers/specs/2026-10-22-xiaozhu-0.6-portrait-design.md`

## Global Constraints

- 产品名保持“小猪修修（原 XUAN）”，永久免费，无订阅、广告、付费墙或强制水印。
- 现有 `.xuan` 扩展名保持不变；0.6.0 必须读取全部 0.5.1 工程。
- 所有模型推理在本地 CPU 完成，运行时不访问网络。
- 最多自动分析 8 张脸；小于 64 像素的人脸不自动精修。
- 自动精修只修改当前选中脸；批量预设应用到全部可信人脸。
- 人像全分辨率应用和整组预设应用各产生一个可撤销历史步骤。
- 参数为 0 时必须逐字节保持原像素。
- 16-bit 图层在点处理与蒙版处理中必须保留高深度数据；无法保持时明确回退且不得静默降级。
- 新模型和转换说明必须满足 Apache-2.0 商业分发要求。
- Windows 和 Linux 必须使用同一模型、同一参数和同一输出规则。
- 任何失败不得留下半成品文件或部分预设修改。
- 每个任务完成前运行对应测试并提交 conventional commit。

## Review Focus

- 无脸、遮挡、低光和极小脸输入：必须给出可恢复错误并保留普通编辑与手动液化。
- 多人脸切换与批处理缩放：必须保持 ID、左右排序和参数作用域稳定。
- 16-bit、透明度和选中蒙版：人像处理不得破坏未选中像素或 alpha。
- 预设加载与整组应用：非法字段、磁盘错误和用户取消不得留下部分修改。
- 批量同名、损坏文件和中途取消：不得覆盖未授权文件或残留临时文件。

```rust
const LANDMARK_MODEL: &[u8] = include_bytes!("../../assets/models/face_landmarks.onnx");

pub struct PortraitModels {
    detector: tract::Runnable,
    landmarks: tract::Runnable,

        let detector = tract::onnx()?

    pub fn landmark_output_shape(&self) -> [usize; 4] { [1, 1, 1, 1434] }
}
```

```rust
impl PortraitWorkspace {
    pub fn analyzing() -> Self {
        Self {
            state: PortraitState::Analyzing,
            faces: Vec::new(),
            selected: 0,
            settings: Vec::new(),
            preview: None,
            compare_original: false,
            error: None,
            liquify: None,
        }
    }

    pub fn from_analysis(result: Result<Vec<FaceLandmarks>, String>) -> anyhow::Result<Self> {
        let mut workspace = Self::analyzing();
        match result {
            Ok(faces) if faces.is_empty() => {
                workspace.state = PortraitState::Ready;
                workspace.error = Some("未检测到人脸".into());
            }
            Ok(faces) => {
                workspace.state = PortraitState::Ready;
                workspace.settings = vec![PortraitSettings::default(); faces.len()];
                workspace.faces = faces;
            }
            Err(error) => {
                workspace.state = PortraitState::Ready;
                workspace.error = Some(error);
            }
        }
        Ok(workspace)
    }

    pub fn cancel(&mut self) {
        self.state = PortraitState::Idle;
        self.faces.clear();
        self.preview = None;
        self.error = None;
    }
```

```rust
        apply_preset_to_document(&mut document, &preset, FacePolicy::NoPortrait).unwrap();
        session.document = document;
        session.history.commit();
    }
}
```
